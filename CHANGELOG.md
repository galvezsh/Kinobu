# Changelog

What changed in the latest version of Kinobu; earlier versions are in git's history and the GitHub releases. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). To bring a computer set up by an earlier version to the latest one, run `bash kinobu.sh --update` (your look is kept).

## [0.3.3] — 2026-11-26

**The skills update.** Your AI agent gets two new ways of working: it agrees a spec with you before it programs, checking today's documentation of what it uses, and a council of independent advisors debates your ideas honestly before you commit to them. Also a Sounds section in Seasons, Papirus' folders in the theme's colour, an account picture from the start, Willow's links in the window and downloads that no longer hang. Run `bash kinobu.sh --update` from the project's folder: the installed `kinobu --update` still runs the copy it already has.

### Added

- **The agent agrees a spec with you before it programs** (spec-driven development, in the skill for developing programs): for a feature or a new app it first writes down what it will do and what not, with checks that prove each part works, tells you in plain words and waits for your yes; then it builds it in small steps, testing each one, and changes the spec before changing what you agreed. For a small fix it lists the checks in the conversation. Before using a library or framework it checks the version installed in your project and reads its official documentation of today, so it does not code from old memory. If you program, it keeps your own spec, stack and way of working and only adds what is missing. Apps with an AI model inside also get its limits and example cases to test it.
- **A council for your decisions** (the `kinobu-council` skill): ask the agent to debate an idea or a choice ("is this a good idea?", "council this") and independent advisors look at it from fixed angles (the case for it, the case against it, the problem it really solves) without seeing your conversation, so they do not just agree with you; a chair weighs them and gives you a plain verdict, what would change it and the first thing to do. Quick by default (four helpers); thorough on request (five advisors and an anonymous review). The agent offers it before big decisions, never runs it on its own, and keeps the verdict in your project when it shapes it.
- **A Sounds section in Seasons**: the sound when you log in and the one when you leave, each on or off, Kinobu's or a sound file of your own (OGG, Opus, WAV, FLAC or MP3), with a Listen button. Your file is copied, so it keeps playing if you move or delete the original; a long one is cut (10 s at login, 4 at logout). It says when Settings' alert sounds are off, since they silence both. Kept in your `look.toml`, so updates and theme changes never touch it; `kinobu-theme pick login-sound|logout-sound kinobu|off|FILE` does the same from the terminal.
- **An account picture from the start**: a user with no picture gets one of GNOME's own at random when Kinobu sets them up or updates them, so the login screen and the top bar's menu never show the empty silhouette. A picture you chose is never replaced; change it in Settings > System > Users.
- **Willow leaves links in the window instead of reading them aloud**: when a web address helps, it shows the full link (now clickable) and says it left it in the window; any address in an answer is taken out of the voice, so it is never spelled out letter by letter.
- **Papirus' folders in the theme's colour**: with Papirus icons, folders take the colour nearest to the palette's accent (violet in Catppuccin, rose in Rosé Pine, orange in Gruvbox, Nord's own blue…), or the one a theme names (`folders` in `theme.toml`). Each user gets their own, without sudo and without changing the folders of other users.

### Fixed

- **Downloads no longer hang when the internet is cut or crawls**: every download gives up after a minute under 10 KB/s or when the server never answers, and tries again three times; Willow's voice models (hundreds of megabytes) go on from where a cut download stopped instead of starting again.
